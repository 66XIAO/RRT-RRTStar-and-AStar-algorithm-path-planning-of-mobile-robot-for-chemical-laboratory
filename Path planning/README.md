# 化学实验室机器人路径规划系统

基于RRT（快速探索随机树）算法的化学实验室机器人路径规划MATLAB程序。

## 功能特点

1. **完整的实验室环境建模**
   - 试剂柜、天平台、器皿柜、操作台、通风橱、水池等实验设备
   - 墙壁边界障碍物
   - 交互点设置（机器人实际操作位置）

2. **RRT路径规划算法**
   - 随机采样树扩展
   - 碰撞检测（考虑机器人半径）
   - 路径优化与平滑

3. **机器人模型**
   - 非点模型（圆形机器人，半径5cm）
   - 方向指示器
   - 运动动画

4. **实验任务流程**
   - 从入口开始，按顺序访问各实验台
   - 12步完整实验流程
   - 每个步骤都有相应的操作延时

5. **路径平滑处理**
   - Ramer-Douglas-Peucker算法简化路径
   - 贝塞尔曲线平滑转角
   - 圆弧过渡

6. **可视化显示**
   - 实验室地图显示
   - 路径规划结果显示
   - 机器人运动动画
   - 操作状态显示

## 文件说明

| 文件名 | 功能描述 |
|--------|----------|
| `lab_robot_rrt.m` | 主程序，运行此文件开始实验 |
| `create_lab_map.m` | 创建实验室地图和障碍物 |
| `plot_lab_map.m` | 绘制实验室地图 |
| `rrt_plan.m` | RRT路径规划算法实现 |
| `smooth_path.m` | 路径平滑处理 |
| `get_operation_delay.m` | 获取操作延时时间 |
| `show_operation_animation.m` | 显示操作动画 |
| `animate_robot.m` | 机器人运动动画 |

## 使用方法

1. 将所有文件放在同一目录下
2. 在MATLAB中打开该目录
3. 运行主程序：
   ```matlab
   lab_robot_rrt
   ```
4. 按提示按任意键开始实验
5. 观察路径规划和机器人运动

## 实验任务流程

1. 入口 → 试剂柜（取试剂）
2. 试剂柜 → 天平台（测量试剂）
3. 天平台 → 操作台1（放置试剂）
4. 操作台1 → 器皿柜（取仪器）
5. 器皿柜 → 操作台1（进行实验）
6. 操作台1 → 通风橱（转移生成物）
7. 通风橱 → 天平台（测生成物参数）
8. 天平台 → 存储柜（存储生成物）
9. 存储柜 → 操作台1（拆下仪器）
10. 操作台1 → 水池（清洗仪器）
11. 水池 → 器皿柜（存储仪器）
12. 器皿柜 → 入口（返回初始位置）

## 算法参数

- `step_size`: 8 cm（RRT扩展步长）
- `max_iterations`: 5000（最大迭代次数）
- `robot_radius`: 5 cm（机器人半径）
- `goal_threshold`: 8 cm（目标阈值）

## 技术特点

1. **碰撞检测**：考虑机器人半径，确保机器人不会与障碍物碰撞
2. **路径平滑**：使用RDP算法和贝塞尔曲线优化路径
3. **非点模型**：机器人用圆形表示，更符合实际情况
4. **交互点设计**：每个实验台都有对应的交互点，位于设备前方便于操作
5. **文字标签**：仅用于显示，不作为障碍物处理
